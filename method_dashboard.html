連結識別出的原則（八分法分群，人工介入）

八分群用三個訊號組合判斷人工介入程度：是否含「原則」、是否含「憲法」、是否含核心詞。代碼如 111，依序代表三個訊號是否存在。

分群代碼特徵組合方法意義人工介入重點
111原則＋憲法＋核心詞形式訊號最完整通常只需校核是否重複或名稱需標準化
101原則＋無憲法＋核心詞具原則與核心詞，但未明示憲法確認是否仍屬憲法原則語境
011無原則＋憲法＋核心詞有憲法脈絡與核心詞，但未出現原則字樣確認是否為原則表述或只是一般憲法敘述
001無原則＋無憲法＋核心詞僅有核心詞訊號高度依賴語境，需人工判斷是否誤入
110原則＋憲法＋無核心詞形式上像原則，但缺核心詞檢查是否為新型表述或抽象泛稱
100原則＋無憲法＋無核心詞只有原則字樣排除非憲法領域或一般語意使用
010無原則＋憲法＋無核心詞只有憲法脈絡多半需確認是否只是背景敘述
000無原則＋無憲法＋無核心詞形式訊號最弱作為高風險檢查區，避免漏掉變形表述
第三章呈現分群規則與人工介入邏輯；完整修正數與比例另見第四章八分群細節頁。

標註規則表

1 合憲文本中可辨識出支持合憲或維持規範效力的判斷語境。
2 違憲文本中可辨識出違憲、失效、牴觸憲法或要求修正的判斷語境。
0 不明確語氣較弱、結論不清，或同時具有多重可能解讀時，不強行標記方向。
-1無判斷詞僅出現原則或背景說明，但未進入合憲性判斷語境。

合憲性方向判斷

0、1、2、-1 是資料表中的方向標記，用來區分原則語句是否進入判斷，以及判斷方向是否明確。

代碼意義判斷訊號第三章定位
1合憲方向尚無牴觸憲法、與憲法意旨尚無不符、仍屬立法形成範圍。建立方向判斷規則
2違憲方向牴觸憲法、違反憲法原則、應失其效力、不予適用、限期修正。建立方向判斷規則
0不明確或不標方向弱語氣、規範性陳述、疑問句、語意未完，或文字不足以判斷方向。避免過度推論
-1本句無可辨識判斷只提到原則或背景敘述，但本句沒有判斷詞；必要時再看後句或人工覆核。保留未判斷狀態
後句助判若本句為 -1，後句可能補出 2、1 或 0；以此保留文本脈絡。
人工修正自動規則無法處理的少數句子，回到原文脈絡人工判斷。
第三章只說明代碼規則與判斷流程；實際數量與比例放在第四章標註成果呈現。

技術平台與實作工具

Google Colab雲端編程與運算環境；作為主要編程平台，用於執行本研究所有 Python 腳本。
Google 試算表雲端資料管理與人工審查工具；儲存各階段成果，並作為人工檢視與驗證介面。
Python主程式語言，具豐富函式庫生態；串接所有研究步驟，實現從資料讀取到分析的自動化。
pandas資料處理與分析函式庫；核心工具，用於整理、篩選、合併所有結構化資料。
Matplotlib / Seaborn / Plotly資料視覺化函式庫；用於第五章，將統計結果視覺化，呈現原則引用趨勢。
WordCloud詞雲生成工具；作為視覺化補充，直觀呈現特定時期的常用詞彙。
sentence-transformers / transformers句向量模型載入與語義比對工具；用於第二節原則資料集建構，處理未知表述之語義分群。
scipy.spatial.distance科學計算函式庫，用於計算向量距離；與句向量模型搭配，計算文本間之語義相似度矩陣。
networkx圖論與網路分析函式庫；依相似度矩陣建立圖結構，並以 connected_components 演算法完成語義分群。
gspread / google.authGoogle API 客戶端函式庫；實現 Python 腳本與 Google 試算表之間的資料讀寫。
本研究並非使用 LLM 自動分析資料，而是以規則、NLP 輔助與人工覆核共同完成資料建置。
